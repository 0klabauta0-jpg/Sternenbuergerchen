# Independent ship verification tools

These tools only inspect standalone Blender candidates. They do not import into
Godot, edit the game's runtime, or certify visual/user acceptance.

## Source / GLB audit

Run with Blender 5.2.3 LTS in a fresh background process:

```powershell
& 'C:/Users/bjoer/AppData/Local/Programs/Blender Foundation/Blender 5.2/blender.exe' -b --factory-startup --python-exit-code 1 -P 'art/frontier_illustrated_20261101/ships/pass05_astra_ultra/qa_tools/verify_ship.py' -- --blend 'path/to/master.blend' --glb 'path/to/export.glb' --collection LOW --length 11 --out 'path/to/audit.json'
```

Use `--length 16` for Cutlass. All mesh objects in the named collection and its
children are evaluated. Lights, reference images and staging floors must be
outside that collection. `--collection '*'` explicitly selects every scene mesh.
Neither input is overwritten. A failure returns a nonzero Blender process code.

The report includes:

- Source BLEND and GLB SHA-256, Blender version, full world bounds and per-object
  triangle counts, transforms, UV counts and material parameters.
- The unmodified `blender-asset-qa/scripts/qa_check.py` result, including every
  warning and error. UV checks are on by default. `--no-uv` is only appropriate
  for intentionally untextured constant materials and itself adds a warning.
- A mesh-island contact graph. Each island must connect to the main assembly
  through actual triangle intersections, vertex/surface contact within 2 mm, or
  explicit closed-volume containment. An isolated multi-part assembly fails even
  if every part in that group touches another part. Detached groups include a
  measured nearest-main-surface diagnostic. Containment adds a review warning.
- Direct, uncompressed GLB binary-accessor reading with finite-data checks and
  node hierarchy transforms. The required world transform is Blender `(X,Y,Z)`
  to glTF/Godot `(X,Z,-Y)`, so Blender `-Y` forward becomes Godot `+Z`.
- A fresh factory-reset Blender import of the exact GLB. Every material-labelled
  triangle corner is matched one-to-one, retaining multiplicities. Position,
  split-normal and UV values are compared, including glTF's V-coordinate flip.
  Material constants or every decoded image pixel are compared semantically:
  sRGB albedo, Non-Color roughness/metallic channels, texture factors, and
  packed GLB roughness in the green channel. PNG byte hashes and decoded pixel
  hashes are recorded. The direct-image graph and Blender importer's standard
  channel separator/scalar-multiplier nodes are supported. This does not rely on
  coincident bounds alone or assert mesh topology equality from a vertex count.

Default tolerances: positions 0.00002 m; direct GLB normal-vector difference
0.0002; fresh Blender normal-vector difference 0.002 (about 0.115 degrees);
constant material values 0.00002. The fresh-import tolerance allows small split
normal reconstruction differences, while the direct GLB check remains stricter.
Actual maxima are always recorded. No error can be accepted through a warning
disposition.

`--accept-warnings dispositions.json` accepts a JSON object mapping warning-text
substrings to concrete manual-review reasons. `pass` means no hard error;
`ready_for_technical_handoff` additionally requires every warning to have a
reason. The caller must inspect any acceptance, not reuse blanket reasons.

Limits: Principled constants/direct image textures only; compressed/sparse GLB
accessors, procedural shaders, normal/AO maps, non-default UV mapping, rigs and
animation intentionally fail as unsupported. Contact checks
are geometric, not a physical load-bearing analysis. Small edge-only gaps may
be conservatively reported as disconnected. Rendering and native engine review
remain separate requirements.

## Tool verification

`selftest_fixture.py` creates a known-good source/GLB pair and deliberately
damaged normal, position and material variants under `selftest/`. A second
fixture contains a detached two-part subassembly. Observed results:

- `good_audit.json`: PASS.
- `bad_normal_audit.json`: FAIL, direct and reimported normal mismatch.
- `bad_position_audit.json`: FAIL, complete corner multiset mismatch.
- `bad_material_audit.json`: FAIL, constant material value mismatch.
- `detached_audit.json`: FAIL, disconnected global contact components, despite
  the basic skill's local floating-parts test finding no error.
- `bad_texture_audit.json`: a valid GLB with exactly one changed embedded albedo
  pixel is rejected by full effective-pixel comparisons. Generated by
  `selftest_texture_corruption.py` from the preserved Buccaneer i04 snapshot.

Read-only real-data test `selftest/r02_audit.json`: R02 Buccaneer's 51,972
triangle corners and materials match source/export/roundtrip. The independent
contact graph finds two isolated pod-landing-gear assemblies. This result is a
tool-validation finding about R02, not a new model acceptance.

`buccaneer_i01/` holds a SHA-bound export snapshot and early diagnostic reports;
it is intentionally preserved as a failed earlier iteration.

Final Buccaneer evidence is `buccaneer_final/audit.json` (i06 source SHA starts
`8b85b71c`, final consolidated GLB SHA starts `f1960edb`): 22,480 triangles,
67,440 compared corners, one contact component, zero errors and zero warnings.
Full positions, normals, UVs, image pixels and material factors passed. This is
technical export evidence only. Earlier failed i05 consolidation evidence is
explicitly preserved as `buccaneer_final/audit_failed_consolidation_i05.json`
and `snapshot_failed_consolidation_i05.glb`.

## Lossless static GLB consolidation

`consolidate_glb.py` combines an ordinary uncompressed static multi-object GLB
into one mesh with one primitive per material, preserving its existing float
attributes and embedded image bytes. This avoids the extra custom-normal
encoding introduced by rebuilding and smoothing all faces of a Blender mesh.
Node world transforms are baked into positions/normals; the existing glTF axis
convention is retained. Skins, animation, morph targets, compression and mixed
attribute schemas inside a material group are deliberately rejected.

```powershell
python art/frontier_illustrated_20261101/ships/pass05_astra_ultra/qa_tools/consolidate_glb.py --input parts.glb --output consolidated.glb
```

Python API: `from consolidate_glb import consolidate; result = consolidate(input,
output)`. Both paths should be distinct. Use `verify_ship.py` against the original
editable LOW collection and final consolidated export afterwards.

Real-data check `consolidation_probe/lossless_i04_audit.json`: 85 mesh nodes
became one mesh / eight material primitives with 20,876 triangles. Source,
direct GLB and fresh import comparisons pass. All nine embedded image hashes
remain unchanged. Failed earlier Blender-rebuild variants are retained in
`consolidation_probe/results.json` as diagnostics, not accepted candidates.

`check_ngon_planarity.py` measures evaluated n-gon planarity using a best-fit SVD
plane and records maximum distances and world coordinates. Its initial final
Buccaneer check found ten warped n-gons, so those were sent back for explicit
triangulation. A source QA n-gon warning is not accepted merely because a cap
looks flat.
