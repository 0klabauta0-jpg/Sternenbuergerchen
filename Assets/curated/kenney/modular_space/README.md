# Modular Space Kit Curated Subset

Status: TASK_194

Source: Kenney Modular Space Kit (1.0)
License: Creative Commons Zero, CC0; see `License.txt`

This folder contains only the curated GLB subset approved by TASK_194 plus the shared `models/Textures/colormap.png` texture referenced by those GLBs. Matching `previews/*.png` files are copied for the Map Editor palette. Do not copy FBX, OBJ, MTL, DAE or STL siblings into this project path.

Use: visual Homebase/FOB/Hangar setpieces and future preview/editor staging only. These assets do not define gameplay collision, walkability or combat state.
