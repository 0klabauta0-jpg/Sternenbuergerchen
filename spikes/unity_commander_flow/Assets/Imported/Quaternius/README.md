# Quaternius Asset Subset

This Unity sidecar contains a small selected FBX subset from Quaternius asset packs. The files are used only for the local `unity_commander_flow` prototype.

- Cyberpunk Kit by Quaternius: https://poly.pizza/bundle/Cyberpunk-Kit-Hkfxa8K8zF
