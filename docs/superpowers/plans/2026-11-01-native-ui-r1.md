# Native UI R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Execution is authorized by the current user request.

**Goal:** Übertrage die bestätigte Bildsprache in bestehende native Spieloberflächen mit gemeinsamem Theme und kompaktem Missionsband.

**Architecture:** Vorhandene Theme-Helfer erweitern, an bestehenden UI-Roots anwenden und harte optische Overrides gezielt angleichen. Layout und Darstellungshelfer verändern keine Gameplay-Wahrheit; vorhandene Presenter, NodePaths und Command-Gates bleiben maßgeblich.

**Tech Stack:** Godot 4.6.2, GDScript, native Theme/StyleBoxFlat, vorhandene Bild-/Iconassets.

**Spec:** `docs/dev/ui_native_design_contract.md`; Task `docs/tasks/TASK_UI_UMSETZUNG_R1_20261101.md`.

## Global Constraints
- Echtzeit ohne Pause, Steuerung nur bis FTL, UI liest State und sendet bestehende Commands.
- Keine per-frame Komplett-Rebuilds oder Tree-Scans; Theme-/Styles wiederverwenden.
- Alle bisherigen Funktionen erreichbar halten, auch kontextuelle Türaktionen und vier Feuerregeln.
- Keine illustrativen Werte oder generierten Typfehler übernehmen; keine Vollscreen-Raster-Controls.

## Review Focus
- Deutsche Langtexte/kleine Auflösung: keine primären Aktionen abschneiden.
- Modal-/Dropdown-/Fokuszustände: lesbare Flächen und keine Klicks auf die Welt darunter.
- Dynamische Karten: dasselbe Theme ohne erneute globale Traversierung; Identität/Zustand korrekt.
- Ausstehende/gesperrte Aktionen: bestehende Gates und Textgründe behalten.
- Bildbelege: ausschließlich tatsächlich gerenderte Viewports, keine Ersatzboards.
