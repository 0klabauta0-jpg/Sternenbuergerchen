# CODEX_TASK_PROMPT_TEMPLATE

Nutze diese Vorlage für jede Codex-Aufgabe in VS / VS Code.

## Startprompt
Lies zuerst:
- docs/PROJECT_BRIEF.md
- docs/ARCHITECTURE.md
- docs/CODEX_RULES.md
- die konkrete Task-Datei

Arbeite im lokalen Projekt:
`C:\dev\SternenBuergerchen`

Wichtige Vorgaben:
- ändere nur die für die Aufgabe nötigen Dateien
- keine großen Refactors
- prüfe lokal im Godot-Projekt, soweit für die Aufgabe sinnvoll
- aktualisiere `docs/IMPLEMENTATION_STATUS.md`
- committe nach erfolgreicher lokaler Prüfung
- pushe nach GitHub, wenn der Remote vorhanden und erreichbar ist
- wenn Push scheitert: klar benennen

Lieferformat:
1. Problem
2. Ursache
3. Änderung
4. betroffene Dateien
5. Risiken / offene Punkte
6. lokale Prüflogik
7. Git-Status / Commit / Push-Status
