# Planmodus — 10.11.2026

Standard ist Plan an, bestehende Vorschau/GO bleiben erhalten. Der getrennte
Schalter am oberen Rand des GO-Buttons aendert nur die Eingabepraeferenz.
Umschalten bestaetigt oder loescht keinen Plan. Bei Plan aus erzeugt ein
Rechtsklick auf gueltigen Boden einen unmittelbar bestaetigten Move fuer den
ausgewaehlten aktiven Trupp ueber die bestehende Command-/Authoritykette.
UI, LZ-Picker und Zielwahl haben Vorrang; kein Durchklicken, keine Einzel-NPC-
Befehle und keine Simulationspause. Ungueltige/gesperrte Ziele bleiben abgelehnt.
