# Playability Manual Open Items

## Audio Feel
- Listen for harsh repetition, volume jumps, missing ambience, and fatiguing UI clicks.

## Visual Readability
- Inspect Full-HD and 1280x720 for subjective text comfort, art scale, contrast, and first-glance hierarchy.

## Drag-and-drop Feel
- Try Homebase and FOB drag-and-drop with a real mouse: hover feedback, drop feedback, rejection feedback, and accidental drop recovery.

## Screen Transitions
- Walk through Main Menu, Homebase, FOB, Mission, Debrief, Editor, and Multiplayer with visible scene transitions and note any awkward blank frames or stale visual state.

## Two-client Multiplayer
- Run a real host/client pair and check lobby readiness, disconnect, map consent, and mission-start authority from both windows.

## Not Repeated Here
- Do not manually repeat automated button reachability, fixed-window rectangles, loadout weight math, roster ID preservation, or report-file existence checks unless an automated failure points to that area.
