# Map Editor Toolbar Tools Checklist

- Start the map editor and check the top toolbar.
- Confirm Select, Brush, Eraser, Height and Patrol are separate icon-first buttons.
- Select a palette item and confirm Brush becomes active.
- Click Eraser and confirm Brush/Select/Height/Patrol are no longer active.
- Erase a tile with an object and confirm only the object layer is cleared.
- Paint a floor/surface over an object and confirm the object is not deleted.
- Use Height on a tile, then Undo.
- Use Select after collapsing inspector sections and confirm Tile Properties still update.
