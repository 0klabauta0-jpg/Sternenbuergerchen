# Editor Lighting Shadow Readability Checklist

- Open the visual recovery reference map in the editor.
- Check the wall, Nature rock cover, cactus, bush and H2 cliff from the default camera angle.
- Toggle the editor shadow debug hook through a test or inspector call if needed and compare readability.
- Confirm shadows add depth but do not hide the selected tile, cliff edge or object anchor.
- Confirm wall and hangar side shadows read as soft depth, not solid black blocks.
- Confirm the bright side of raised tiles remains readable after one camera rotation.
- Confirm no new warning flood appears while the map is open.
