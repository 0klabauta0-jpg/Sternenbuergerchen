# Playability Layout Remaining Visual Checklist

## Full-HD
- Open Main Menu, Homebase, FOB and Mission HUD at 1920x1080.
- Confirm fixed windows do not shift after data refreshes.
- Check that primary buttons remain fully visible and readable.

## 1280x720
- Open Main Menu and Multiplayer Lobby.
- Treat Drop Light Full-HD screens as warning-only unless a future task explicitly supports this size.

## Long Content
- Use long roster names, long callsigns and long character biographies.
- Scroll Homebase roster, transfer team, character sheet, FOB loadout, FOB flightdeck and Mission HUD panels.
- Confirm scrollbars can be operated with mouse wheel and drag.

## Manual Judgement
- Check visual text clipping, focus rings, hover states and intentional icon/portrait masks.
- Decide whether any abbreviated labels need a separate text pass.
