# Map Editor Inspector Panels Checklist

- Start the map editor at a 1920x1080 window.
- Confirm Tile Properties are visible immediately.
- Confirm the right property/tools panel scrolls vertically when the content is longer than the visible panel.
- Collapse Map Settings and confirm Tile Properties remain visible.
- Collapse Markers and confirm marker values are not deleted.
- Expand Mission Scenario, edit a field, collapse and expand again.
- Confirm the edited field remains intact.
- Confirm long scenario controls are reachable by the right panel without covering the map authoring surface.
