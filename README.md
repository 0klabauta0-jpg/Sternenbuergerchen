# Sternenbürgerchen

Ein Echtzeit-Taktikspiel mit Heimatbasis, Raumreise und Einsätzen auf Hexfeldern.
Entwickelt mit Godot 4.6.2; das Projekt befindet sich im Playtest.

- [Windows-Playtest herunterladen](https://github.com/0klabauta0-jpg/Sternenbuergerchen-Downloads/releases/tag/playtest-2026-11-14-r2)
- [Spielanleitung mit Trefferrechner](https://sternenbuergerchen-spielanleitung.klabauta.chatgpt.site)
- [Referenzgalerie: 71 Bilder in sechs Rubriken](https://github.com/0klabauta0-jpg/Sternenbuergerchen-Downloads/tree/main/referenzen-r2)
- [Rüstungen: leicht, mittel und schwer](https://github.com/0klabauta0-jpg/Sternenbuergerchen-Downloads/tree/main/referenzen-r2/01_Ruestungen)
